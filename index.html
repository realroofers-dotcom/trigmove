Reproduce it yourself

Every ownership figure in this docket came from the same free tool. It takes about ten minutes.

  1. Open sec.gov/edgar/search — the SEC's full-text search, covering electronic filings since 2001.
  2. Type a name in quotation marks and press Search. For example: "Empery Asset Management"
  3. On the results page, open the Entity panel on the left. It lists every filer whose documents contain that phrase, with a count for each.
  4. Use Show Columns → Incorporated to add each issuer's state or country of incorporation to the results table.
